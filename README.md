# Саня — iOS (MVP v0.1)

Одно приложение-лаунчер: главный экран с модулями, внутри Саня, Смены, Книга Мастера, Таймеры и Плеер. Остальные модули — плитки «скоро».

* SwiftUI, iOS 17+, iPhone, тёмная тема, русский интерфейс.
* Проект генерируется XcodeGen из `project.yml` — `.xcodeproj` в репо нет.
* Собирается без Mac: GitHub Actions (`.github/workflows/ios.yml`) на macOS-раннере:
  * сборка под симулятор, UI-тест-прогулка, скриншоты и 3 видео-отчёта (артефакт `sanya-media`);
  * неподписанный `.ipa` для SideStore (артефакт `sanya-ipa`).

## Модули v0.1
| Модуль | Что работает | Заглушка / потом |
|---|---|---|
| 🗣 Саня | чат, голосовой ввод (Speech ru-RU), озвучка ответов, локальные команды: «открой смены», «таймер на 5 минут», «когда моя смена», «включи музыку» | ИИ — любой OpenAI-совместимый адрес в ⚙︎ (ключ в Keychain), без него — демо-режим |
| 🍟 Смены | неделя/месяц, часы, ≈ зарплата по ставке, ручное добавление/правка, импорт скрина (Vision OCR + локальный разбор), напоминания, отсчёт смены на острове | ИИ-разбор скрина на сервере, Google Календарь, виджет |
| 📖 Книга Мастера | WKWebView на akriv777-png.github.io/kniga-mastera, кэш, назад/домой, JS-мост `sanya` (вибрация) | — |
| ⏱ Таймеры | пресеты, свой таймер, кольцо, уведомление, обратный отсчёт на острове | фокус-режим, будильники AlarmKit |
| 🎧 Плеер | импорт из «Файлов», фон, экран блокировки, визуализатор, остров: обложка-бейдж + эквалайзер в цвет обложки, стили «руна»/«пламя» | настоящая обложка на острове (нужна App Group), FFT, караоке |

## Установка на iPhone
Скачай `Sanya-v0.1-unsigned.ipa` из артефактов последнего зелёного запуска → SideStore → «+» → выбрать ipa.
